# lewsapps.com

The Lew's Apps website, served by GitHub Pages from the `docs/` folder.

- `apps.json` — every app's name, description, version and download link. Edit this to release a new version.
- `assets/` — stylesheet, logos and app icons.
- `build.py` — run `python3 build.py` to regenerate the pages in `docs/` after editing.
